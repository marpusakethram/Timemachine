# Time Machine v1.0.0

A decision lab for startup founders that runs in your browser, with a fully working
demo that needs no API key.

- Compare bootstrapping, hiring and a pretend priced round side by side.
- Change growth, capital, costs and more. Runway and ownership update instantly.
- Save in your browser, and export or import JSON, a monthly CSV, a PNG or a share link.
- Optional Gemini suggestions with consent and review, free-tier checks by you,
  lasting request budgets and no paid fallback.
- A redesigned home page and workspace with a finance-tool look, light and dark mode,
  a new TM logo, and a layout that works on phones.
- Includes the architecture diagram (SVG and PNG), setup guide, assumptions, license
  list, screenshots and a real browser recording.

Run it with Node.js 22.12+: `npm ci`, then `npm run dev`. Open
http://127.0.0.1:3000 and click the fictional SaaS demo.

Everything it shows is a "what if". Live Gemini wasn't tested: the AI connection was
checked with labeled fixtures and the real "no key" error path. No paid service or
public hosting is needed.

See [VERIFICATION.md](VERIFICATION.md) for what was tested and the results.
