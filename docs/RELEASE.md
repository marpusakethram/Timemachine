# Time Machine v1.0.0

A local-first startup decision lab with a fully working no-key SaaS demo.

- Compare bootstrap, hiring and hypothetical priced-round branches.
- Edit growth, capital, costs and other inputs; runway and ownership update immediately.
- Save locally and export/import JSON, monthly CSV, PNG or a small share link.
- Use optional Gemini candidate generation with explicit consent/review, free-model
  operator verification, durable request budgets and no paid failover.
- Explore the redesigned live homepage, cash-chart-first workspace and mobile layout.
- Includes the layered architecture diagram in SVG/PNG, source, setup guide,
  assumptions, license inventory, screenshots and real browser recording.

Validated: TypeScript, production build, 41 unit/integration tests and 4 browser
workflows. npm audit reports zero vulnerabilities.

Run with Node.js 22.12+: `npm ci`, then `npm run dev`.
Open http://127.0.0.1:3000 and choose the fictional SaaS demo.

All outputs are conditional and hypothetical. Live Gemini was not exercised:
the connector was validated with labeled fixtures and the real no-key failure path.
No paid service or public hosting is required.
